# 고요한 숲

웹캠 앞에서 검지를 움직여 빛을 옮기고, 숲속 네 캐릭터를 깨우는 인터랙션입니다.
HTML 하나에 화면, 캐릭터, 글꼴, 소리와 손 인식 모델이 포함되어 있습니다.

체험 전에 “너도 누군가의 밤에 작은 빛이 되어 줄 수 있어.”라는 김심리월드의 인사가 먼저 나타납니다.
약 5초 뒤 조작 안내로 이어지며, **숲으로 가기**를 누르면 바로 넘어갈 수 있습니다. 이 도입 화면에서는 카메라와 소리가 켜지지 않습니다.

## 실행

1. [고요한숲.zip](./고요한숲.zip)을 내려받아 압축을 풉니다.
2. `고요한숲.html`을 Chrome에서 엽니다.
3. 도입 인사를 읽고 조작 안내가 나타나면 **시작하기**를 누릅니다.
4. 카메라 사용을 허용하고, 손 전체가 카메라에 보이도록 검지를 펴서 캐릭터 주변을 천천히 맴돕니다.

별도 패키지 설치나 빌드, 서버 실행은 필요하지 않습니다. 카메라를 끄면 마우스·터치·방향키로 조작할 수 있습니다.
카메라 영상은 브라우저 안에서 손 인식에만 사용하며 저장하거나 업로드하지 않습니다. 마이크는 사용하지 않습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 손끝 | 카메라가 켜져 있을 때 빛 이동 |
| 마우스·터치·방향키 | 카메라가 꺼져 있을 때 빛 이동 |
| C | 카메라 켜기·끄기 |
| M | 소리 켜기·끄기 |
| R | 처음으로 |
| H | 조작 안내 |
| F | 전체화면 |

## 포함된 수정

- 체험 시작 전 짧은 인사와 부드러운 문장 전환을 추가했습니다. 키보드, 작은 화면, 동작 줄이기 설정을 지원하며 다른 탭을 보는 동안에는 읽기 시간이 멈춥니다.
- 카메라 미리보기와 빛의 좌우 방향을 일치시켰습니다.
- 손이 화면 밖으로 나가거나 인식 결과가 늦을 때 오래된 위치를 해제하고, 재진입하면 추적을 이어갑니다.
- 효과음 예약 충돌로 빛과 캐릭터의 화면 갱신이 중단되던 오류를 수정했습니다. 소리 오류는 화면 갱신을 중단시키지 않습니다.

## 검증

Node.js가 설치된 환경에서 이 저장소 폴더의 PowerShell을 열고 실행합니다.

```powershell
npm.cmd test
```

정상 결과는 **13개 검사 통과, 실패 0개**입니다. 별도 npm 패키지를 설치하지 않습니다.

자동 검사는 손 추적, 이탈·복귀, 지연 결과, 세션 종료, 오디오 예약 및 오류 처리, 화면 갱신 재개를 확인합니다.
Chrome에서는 소리를 켜고 네 캐릭터를 깨우는 동작, 의도적인 효과음 오류 이후 화면 갱신, 손 이탈·재진입 12회를 검증했습니다.
카메라 통합 검사는 테스트 영상과 실제 손 인식 모델을 사용했습니다. 실제 웹캠·조명 환경에서의 체감은 별도로 확인해야 합니다.

내장 자산의 라이선스 및 출처 고지는 HTML에 포함되어 있습니다.
